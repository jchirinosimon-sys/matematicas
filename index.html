Bienvenido a la Calculadora Estadística

1. Ingresa tus datos

Escribe los valores de Li (límite inferior), Ls (límite superior) y fi (frecuencia) en la tabla. Puedes agregar o eliminar filas con los botones.

2. Cálculos automáticos

Los valores de Fa y Mc se calculan automáticamente mientras escribes.

3. Resultados instantáneos

La Media, Mediana, Moda y Rango se actualizan en tiempo real junto con el desarrollo paso a paso.

4. Datos de ejemplo

Usa el botón "Cargar Ejemplo" para cargar datos predefinidos y explorar cómo funciona la calculadora.

¿Qué es la Marca de Clase?

Mc = (Li + Ls) ÷ 2

La marca de clase representa el punto medio de cada intervalo y se utiliza para calcular la media de datos agrupados.
